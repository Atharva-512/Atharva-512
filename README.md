### Featured Projects

**[Restaurant POS ELT Platform](https://github.com/Atharva-512/restaurant-pos-elt-pipeline)** — end-to-end analytics platform for restaurant operations<br/>
Bronze → Silver → Gold pipeline into a DuckDB warehouse with star-schema modeling, feeding an interactive Power BI layer.<br/>
`Python` `SQL` `DuckDB` `Power BI` &nbsp; ![Stars](https://img.shields.io/github/stars/Atharva-512/restaurant-pos-elt-pipeline?style=flat-square&label=)  ![Last Commit](https://img.shields.io/github/last-commit/Atharva-512/restaurant-pos-elt-pipeline?style=flat-square&label=updated)<br/>

**[Azure E-Commerce Data Pipeline](https://github.com/Atharva-512/azure-ecommerce-data-pipeline)** — cloud-native batch pipeline for e-commerce data<br/>
Ingestion through Azure Data Factory and Databricks, landing in ADLS Gen2 and modeled in Synapse Analytics.<br/>
`ADF` `Databricks` `ADLS Gen2` `Synapse` &nbsp; ![Stars](https://img.shields.io/github/stars/Atharva-512/azure-ecommerce-data-pipeline?style=flat-square&label=)  ![Last Commit](https://img.shields.io/github/last-commit/Atharva-512/azure-ecommerce-data-pipeline?style=flat-square&label=updated)<br/>
*Impact: end-to-end reference pipeline for cloud batch ingestion at scale.*

**[Real-Time Financial Transaction Monitoring](https://github.com/Atharva-512/real-time-financial-monitoring)** — low-latency streaming platform<br/>
Kafka producers feed Spark Structured Streaming jobs for near-real-time transaction monitoring.<br/>
`Kafka` `Spark Streaming` `Python` &nbsp; ![Stars](https://img.shields.io/github/stars/Atharva-512/real-time-financial-monitoring?style=flat-square&label=)  ![Last Commit](https://img.shields.io/github/last-commit/Atharva-512/real-time-financial-monitoring?style=flat-square&label=updated)<br/>
*Impact: sub-second ingestion-to-alert latency for anomaly detection use cases.*

**[Retail Supply Chain Data Pipeline](https://github.com/Atharva-512/retail-supply-chain-pipeline)** — batch pipeline for supply chain analytics<br/>
PySpark transformations orchestrated with Airflow, covering ingestion through analytical reporting.<br/>
`PySpark` `Airflow` `SQL` &nbsp; ![Stars](https://img.shields.io/github/stars/Atharva-512/retail-supply-chain-pipeline?style=flat-square&label=)  ![Last Commit](https://img.shields.io/github/last-commit/Atharva-512/retail-supply-chain-pipeline?style=flat-square&label=updated)<br/>
